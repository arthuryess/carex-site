# Carex site

The public support page and privacy policy for the Carex iOS app, served
with GitHub Pages:

- Support: https://arthuryess.github.io/carex-site/
- Privacy policy: https://arthuryess.github.io/carex-site/privacy.html

The app's code lives in a separate, private repository. These addresses are
also set in the app (`AppConstants.supportUrl` and
`AppConstants.privacyPolicyUrl`) and in App Store Connect, so keep the file
names unchanged.
